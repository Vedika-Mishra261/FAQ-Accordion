# FAQ Accordion

A simple, interactive, and responsive FAQ Accordion website built using HTML, CSS, and JavaScript as part of my **Web Development Internship at Veda Technology**.

## 📌 About the Project

The FAQ Accordion allows users to click on a question to expand and view its answer. Clicking the same question again collapses the answer.

This project also includes technical interview questions based on my internship tasks, covering JavaScript, form validation, calculators, random quote generators, and image galleries.

## ✨ Features

- Expandable and collapsible FAQ questions
- Interactive interview questions
- Smooth accordion animations
- Active question highlighting
- Plus (+) and minus (-) icons
- Only one answer open at a time
- Responsive design for mobile, tablet, and desktop
- Simple and beginner-friendly code

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project Folder

```bash
cd FAQ-Accordion
```

### 3. Run the Project

Open the `index.html` file in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.
