const height = Number(input.value);

JavaScript has one main Number type for whole and decimal numbers. Decimals use floating-point values, so small rounding errors can happen. For example, 0.1 + 0.2 may print as 0.30000000000000004. Round the result when needed.

const total = Math.round((0.1 + 0.2) * 100) / 100;

Use if, else if, and else to show the message that matches the value.

  message = "Normal";
} else {
  message = "Above normal";
}

eval() runs a string as JavaScript code. It is unsafe with user input, harder to debug, and slower than normal code. Use Number() and operators instead.

const result = Number(a) + Number(b);

Keep the current number, previous number, and selected operator in one object or in separate variables. Update the object after every button click.

const state = {

  previous: "",
  operator: ""
};

Check the second number before dividing. Show a friendly message instead of allowing Infinity in the display.

if (b === 0) {

  display.value = String(a / b);
}

Math.random() returns a decimal from 0 up to, but not including, 1. Multiply it by the array length and use Math.floor() to get a valid index.

const index = Math.floor(Math.random() * quotes.length);

Use an array of objects. Each object can hold the quote text and its author.

const quotes = [
  { text: "Keep learning every day.", author: "Unknown" },
  { text: "Small steps make big results.", author: "Unknown" }
];

Remember the last index and choose a new one until it is different. This works when the array has more than one quote.

let lastIndex = -1;
let index;

do {
  index = Math.floor(Math.random() * quotes.length);
} while (quotes.length > 1 && index === lastIndex);

lastIndex = index;

Alt text describes an image for screen readers and appears when an image cannot load. It also helps search engines understand the image. Use alt="" only for decorative images.

<img src="gallery-1.jpg" alt="Blue mountain lake at sunrise">

CSS Grid is a layout system that arranges items in rows and columns. It is useful for an image gallery because the images can sit in equal columns and wrap on smaller screens.

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
